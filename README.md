# 🐧 Script Interativo de Pós-Instalação para Ubuntu

Este script interativo facilita a configuração inicial de sistemas Ubuntu, com foco em ferramentas para desenvolvedores, personalização do terminal e da Dock do GNOME.

## ⚙️ Recursos

- Atualização do sistema
- Instalação de pacotes essenciais para desenvolvimento
- Instalação e configuração do Zsh com:
  - Oh My Zsh
  - zsh-autosuggestions
  - zsh-syntax-highlighting
- Personalização da Dock do GNOME
- Interatividade: você escolhe o que deseja instalar!

## 🚀 Como Usar

`bash
git clone https://github.com/seu-usuario/ubuntu-pos-instalacao-interativo.git
cd ubuntu-pos-instalacao-interativo
chmod +x setup.sh
./setup.sh
